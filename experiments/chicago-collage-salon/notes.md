# Chicago Collage Salon

All 345 works from [The Chicago Collage Project gallery](https://www.thechicagocollageproject.com/new-gallery) become a spatial, rearrangeable exhibition.

The layout buttons transform the same set of CSS3D artwork cards between a salon wall, spiral, globe, and ribbon. Drag to orbit, scroll to move through the room, select a work for its artist credit, and enable **Drift** for an automatic exhibition path.

The local `images/artworks/` folder contains one optimized AVIF file per gallery item in source order; `images/thumbs/` keeps the 345-card overview light. Artist credit, original dimensions, local paths, and the direct source URL are retained in `Artworks.js`.
