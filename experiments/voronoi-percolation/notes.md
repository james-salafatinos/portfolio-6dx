# Voronoi Percolation

A continuum-percolation visualization built on a moving Voronoi/Delaunay graph.

Each site gets a fixed random threshold `u ∈ [0,1]`. The global parameter `p` determines whether that cell is open (`u ≤ p`). Open Delaunay neighbors are merged with Union-Find, so connected clusters share a color. A cluster that touches both opposite boundaries is reported as percolating.

The geometry is recomputed continuously while sites move. The Delaunay triangulation uses Bowyer–Watson; Voronoi cells are generated by clipping each site's bounding box against the perpendicular bisectors of its Delaunay neighbors.

## Controls

- **p (threshold)** — sweep from closed to open cells without rerandomizing thresholds.
- **N (sites)** — number of moving sites.
- **Motion Mode** — random walk or Lissajous motion.
- **Walk Speed / Speed** — motion controls.
- **Play / Pause** — freeze geometry motion.
- **Regenerate** — draw new site thresholds.
- **Show Voronoi / Delaunay / Points** — rendering toggles.

## 6DX migration

This experiment was migrated from Portfolio 5DX as the first substantial compatibility test. The simulation logic remains self-contained in the experiment folder, while Three.js and lil-gui are provided as shared 6DX platform dependencies. The experiment conforms to the 6DX `Experiment` lifecycle (`start`, `resize`, `destroy`) rather than requiring special server routing.
